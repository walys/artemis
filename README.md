# Artemis — Calculadora Laboratorial Veterinária

Sistema web para gerenciamento laboratorial veterinário.

## Stack
- Laravel 12 + Inertia.js + Svelte 5
- MySQL 8.4
- Docker (Laravel Sail)
- Vite
- Svelte

## Como rodar

```bash
./vendor/bin/sail up -d
./vendor/bin/sail npm install
./vendor/bin/sail npm run dev
